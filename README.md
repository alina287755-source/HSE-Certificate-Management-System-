# Система учёта охраны труда и промышленной безопасности

Внутреннее веб-приложение для подразделения (~25 сотрудников): карточки сотрудников,
сертификация, сроки, статусы, документы.

**Этап 1 (сделано сейчас):** структура проекта, база данных, авторизация, роли,
главное меню, главная страница, карточка сотрудника, модуль «Сертификация»,
загрузка документов.

Остальные разделы (Обучение, Инструктажи, Проверка знаний, СИЗ, Уведомления,
Отчёты, Настройки) будут добавлены на следующих этапах — сейчас в меню они
показаны серым с пометкой «скоро», чтобы уже было видно общую структуру.

## Что нужно, чтобы всё заработало (простыми словами)

Приложению нужна база данных. Мы используем бесплатный сервис Supabase —
он и хранит данные, и делает вход по паролю, и хранит файлы (сканы документов).

### Шаг 1. Создать проект в Supabase

1. Откройте https://supabase.com и войдите (можно через GitHub или e-mail).
2. Нажмите **New Project**.
3. Укажите название проекта (например, «Охрана труда»), придумайте пароль
   для базы данных (сохраните его отдельно, он ещё пригодится) и выберите
   регион поближе (например, Europe).
4. Подождите 1–2 минуты, пока Supabase создаст проект.

### Шаг 2. Загрузить структуру базы данных

1. В левом меню Supabase откройте **SQL Editor**.
2. Нажмите **New query**.
3. Откройте файл `supabase/migrations/0001_init.sql` из этого проекта,
   скопируйте весь его текст и вставьте в редактор. Нажмите **Run**.
4. Повторите то же самое с файлом `supabase/migrations/0002_storage.sql`.

После этого в разделе **Table Editor** вы увидите таблицы: `employees`
(сотрудники), `certifications` (сертификаты), `profiles` (пользователи и
роли), `documents` (документы), `settings` (настройки).

### Шаг 3. Подключить приложение к вашей базе

1. В Supabase зайдите в **Project Settings → API**.
2. Найдите там **Project URL** и **anon public key** — это два значения,
   которые нужно скопировать.
3. В папке проекта найдите файл `.env.example`, сделайте его копию и
   переименуйте копию в `.env`.
4. Откройте `.env` и вставьте туда свои значения:

```
VITE_SUPABASE_URL=вставьте сюда Project URL
VITE_SUPABASE_ANON_KEY=вставьте сюда anon public key
```

### Шаг 4. Завести первого пользователя-администратора

1. В Supabase откройте **Authentication → Users → Add user**.
2. Укажите e-mail и пароль администратора, нажмите **Create user**.
3. Перейдите в **Table Editor → profiles** — там уже появится строка с
   этим пользователем (создаётся автоматически).
4. Откройте эту строку и в поле **role** впишите `admin` вместо `employee`.
   Сохраните.

Теперь этим e-mail и паролем можно входить в приложение как администратор.

Так же можно позже создать пользователей для руководителя (`role = manager`)
и для сотрудников (`role = employee`, плюс в поле `employee_id` указать,
какая карточка сотрудника ему принадлежит — тогда он увидит только её).

### Шаг 5. Запустить приложение

Если у вас установлен Node.js:

```
npm install
npm run dev
```

Приложение откроется в браузере, обычно по адресу http://localhost:5173

Для «боевого» использования (чтобы сотрудники заходили по ссылке в интернете)
проект нужно разместить на хостинге — например, Vercel или Netlify. Это можно
сделать на одном из следующих этапов, если понадобится.

## Как добавить сотрудника и сертификат (проверка результата)

1. Войдите как администратор.
2. Пока в интерфейсе нет формы «Добавить сотрудника» с полным сохранением
   (кнопка есть, но подключим её на следующем этапе вместе с проверкой всех
   полей) — самый быстрый способ добавить первых сотрудников для проверки:
   откройте в Supabase **Table Editor → employees → Insert row** и заполните
   ФИО, табельный номер, цех, должность.
3. Затем в приложении откройте раздел **Сотрудники**, найдите добавленного
   человека, откройте его карточку.
4. На вкладке **Обучение и сертификация** нажмите **+ Добавить сертификат**,
   заполните вид сертификата и даты — статус (🟢🟡🔴) рассчитается
   автоматически по дате окончания.
5. Там же можно сразу загрузить скан удостоверения (PDF, JPG или PNG).
6. Зайдите на **Главную** — там появятся правильные цифры по сотрудникам
   и сертификатам, и можно нажать на карточку, чтобы перейти к списку.

## Структура проекта (для справки)

```
src/
  pages/            — страницы (Главная, Сотрудники, Карточка, Сертификация, Вход)
  components/       — переиспользуемые части интерфейса (статус, загрузка файлов, меню)
  context/          — вход пользователя и его роль
  lib/supabase.ts   — подключение к базе данных
  types/db.ts       — описание структуры данных
supabase/migrations/ — SQL-скрипты структуры базы данных (запускаются в Supabase один раз)
```
